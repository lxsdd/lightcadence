# LightCadence

Dynamic lighting for Home Assistant.

An in-development local, cross-vendor lighting platform: native HA integration, separate real-time engine and shared responsive interface. This repository is the single development source. No release, installation candidate or device support is currently qualified. Public source access is not a license grant; licensing remains undecided.

See AGENTS.md for development and qualification boundaries.

For owner-local, SHA-bound preview preparation and offline HA code switching, see [local preview deployment](docs/local-preview-deployment.md). No actual deployment is implied.
